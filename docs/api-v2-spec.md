# Device API v2 -- superseded

The v2 protocol (firmware up to 0.10.x) is replaced by **API v3** from firmware 0.11.0:
[api-v3-spec.md](api-v3-spec.md) is the protocol, [api-reference.md](api-reference.md) lists every resource, and
section 9 of the spec maps each v2 resource to its v3 place. The framing and the CRC are unchanged.

The full v2 design document is in git history (`git log -- docs/api-v2-spec.md`).
