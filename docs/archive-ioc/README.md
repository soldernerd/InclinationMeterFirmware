# Archived CubeMX project files — NOT authoritative

The live CubeMX project for REV B is **`WylerLeveltronic.ioc`** at the repo
root. The generated `Core/` and `Drivers/` code is produced from it (see
`docs/cubemx_configuration_checklist.md` — "Code has been generated from
`WylerLeveltronic.ioc`"). Regenerate only from that file.

Kept here for history:

| File | What it is |
|------|------------|
| `InclinationMeterFirmware.ioc` | The original REV A project (Apr 2026). Predates every REV B pin change — a regen from this reverts the board. |
| `NewPinout/NewPinout.ioc`      | An intermediate scratch pinout from the REV A→B migration (Aug 2026). Superseded by `WylerLeveltronic.ioc`. |
